# Materials Analytics 1.7.1 — примітки до релізу

## Основна зміна

Додаток більше не обмежений одним аркушем для розрахунків. Після завантаження Excel-файлу можна одночасно призначити ролі кільком аркушам:

- **Zużycie** — використання матеріалів;
- **Zapasy** — залишки;
- **Przyjęcia** — надходження;
- **Otwarte zamówienia** — відкриті замовлення;
- **Kartoteka materiałów** — довідник матеріалів;
- **Ignoruj** — службові або архівні аркуші.

Кожен аркуш має власний рядок заголовків і власне мапування.

## Як використати два аркуші

1. Завантажити Excel-файл.
2. У блоці **Model danych skoroszytu** вибрати:
   - для першого аркуша роль `Zużycie`;
   - для другого аркуша роль `Zapasy`.
3. Перевірити мапування колонок для кожного аркуша.
4. Для запасів вибрати:
   - `Aktualny snapshot`, якщо це вже фактичний залишок;
   - `Stan początkowy`, якщо від нього потрібно відняти використання та додати надходження.
5. Вибрати ключ зв’язку або залишити `Automatycznie`.
6. Натиснути **Zbuduj model danych**.
7. Перевірити аудиторський підсумок і перейти до мапування/аналізу.

## Формула початкового залишку

```text
Залишок = початковий запас
          + надходження після дати запасу
          - використання після дати запасу
```

Актуальний snapshot не зменшується повторно.
