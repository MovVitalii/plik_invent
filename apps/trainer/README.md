# Excel Analytics Trainer 1.0.0

Локальний браузерний тренажер для швидкого опрацювання Excel/CSV. Інтерфейс застосунку — польською.

## Запуск

### Найпростіше
Розпакуй ZIP і відкрий `index.html` у сучасному браузері.

### Через локальний сервер
У каталозі проєкту виконай:

```bash
python -m http.server 8000
```

Потім відкрий `http://localhost:8000`.

Для Windows також додано `START_WINDOWS.bat`, для Linux/macOS — `start.sh`.

## Можливості

- імпорт `.xlsx`, `.xls`, `.xlsm`, `.xlsb`, `.ods`, `.csv`, `.tsv`;
- вибір аркуша;
- попередній перегляд, пошук, сортування та пагінація;
- контроль якості: пусті клітинки, дублікати, змішані типи, проблемні пробіли;
- очищення тексту, заміна значень, видалення пустих рядків і дублікатів;
- обчислення `SUM`, `AVERAGE`, `COUNT`, `COUNTA`, `MIN`, `MAX` та варіанти `...IFS`;
- Pivot Table з рядками, колонками, значеннями та фільтрами;
- стовпчиковий, горизонтальний, лінійний і круговий графік;
- експорт очищених даних та повного аналітичного Excel-звіту;
- навчальна панель із відповідниками інструментів Excel.

## Перевірка

Збірка пройшла:

- синтаксичну перевірку всіх 13 JavaScript-файлів через `node --check`;
- браузерний запуск усіх модулів без помилок;
- реальний імпорт тестового `.xlsx` із двома аркушами;
- контроль якості та виявлення дубліката;
- очищення пробілів;
- `SUMIFS` для колонки `Cena.netto` з крапкою в назві;
- Pivot з агрегацією `average` і коректним `Razem`;
- побудову графіка;
- створення Excel workbook/worksheet через SheetJS.

Докладний результат: `BUILD-REPORT.md`.

## Обмеження

- максимальний розмір імпортованого файлу: 50 MB;
- графік показує до 200 категорій;
- застосунок працює локально та не надсилає дані на сервер;
- для дуже великих наборів швидкість залежить від оперативної пам’яті браузера.
